# Политика конфиденциальности Lumeo (RU, заглушка)

> Требуется проверка юристом до публичного релиза.

1. **Какие данные:** аккаунт (email, username, display name), профиль/статусы, друзья/Squad/Session, метаданные сообщений (без содержимого E2EE-чатов), покупки/ledger, диагностика, push-токены.
2. **E2EE:** содержимое личных/групповых чатов шифруется на устройстве; сервер хранит только шифротекст и метаданные (id, отправитель, время, keyId).
3. **Цели:** работа сервиса, безопасность/модерация по жалобам (по метаданным), уведомления, аналитика.
4. **Хранение:** beta — PostgreSQL + локальное файловое хранилище; сроки — по необходимости сервиса и закону.
5. **Права:** доступ, исправление, удаление, экспорт, ограничение обработки, отзыв согласий — Настройки → Data и запрос в поддержку.
6. **Дети 12+:** данные несовершеннолетних обрабатываются с учетом применимого права; жалобы на детский контент — в приоритетном порядке.
7. **Контакты:** поддержка (email будет указан перед релизом).
