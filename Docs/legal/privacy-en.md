# Lumeo Privacy Policy (EN, placeholder)

> Requires review by a lawyer before public release.

1. **Data we process:** account (email, username, display name), profile/statuses, friends/squads/sessions, message *metadata* (no E2EE chat contents), purchases/ledger, diagnostics, push tokens.
2. **E2EE:** 1-1/group chat contents are encrypted on-device; server stores only ciphertext + metadata (id, sender, timestamps, keyId).
3. **Purposes:** operate the service, safety/moderation on reports (metadata-based), notifications, analytics.
4. **Retention:** beta — PostgreSQL + local file storage; kept as needed for service and law.
5. **Rights:** access, rectify, delete, export, restrict, withdraw consent — Settings → Data and support request.
6. **Children 12+:** minors' data handled per applicable law; child-safety reports prioritized.
7. **Contact:** support (email to be published before release).
