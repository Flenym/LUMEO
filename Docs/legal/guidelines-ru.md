# Правила сообщества Lumeo (RU, заглушка)

> Требуется проверка юристом до публичного релиза.

1. **Уважайте других:** без травли, угроз, дискриминации, NSFW/насилия, спама, мошенничества.
2. **Возраст 12+:** контент должен быть уместен для 12+; детский небезопасный контент запрещен и ведет к блокировке + передаче по закону при необходимости.
3. **Публичное модерируется:** статусы, профили, Squad-названия, Workshop проходят фильтры/модерацию. Чаты без словарного фильтра, но жалобы работают: прикладывайте контекст, модерация видит только метаданные E2EE.
4. **Честная игра:** без накруток XP/streak/голосов, без массового спама приглашениями.
5. **Жалобы:** профиль/сообщение → Report; кластеризация ускоряет разбор; ложные жалобы наказуемы.
6. **Санкции:** предупреждение → мут → бан; апелляция через поддержку.
